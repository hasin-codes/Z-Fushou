**Edge function name:** `live-timeline`
**File:** `supabase/functions/live-timeline/index.ts`
**Deploy:** `supabase functions deploy live-timeline --no-verify-jwt`

**URL:** `GET /live-timeline`

**Query params:**

| Param | Default | Description |
|---|---|---|
| `status` | `open` | `open`, `closed`, or `all` |
| `limit` | `50` | Max cases to return (capped at 200) |
| `attention` | — | Filter by attention score: `high`, `high,critical` etc. |

**Response:**

**How it works:**
- Queries `live_cases` sorted by `updated_at DESC`
- Fetches last 5 events per case from `live_case_events`
- Returns stats (open count + closed today count)
- Follows the exact same pattern as all other edge functions (auth, CORS, error handling, logging)
- Not date-based — returns whatever is current, sorted by latest update
- Frontend polls every 15-30 seconds; when a case gets a new summary, its `updated_at` changes and it jumps to the top
